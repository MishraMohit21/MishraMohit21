### About

B.Tech Computer Science graduate and Kernel Engineering Intern on the BSP team at **Harman International**, working on AOSP, the QNX hypervisor, and Linux kernel drivers for automotive cockpit platforms.

Submitted driver patches to the upstream Linux kernel staging tree (`sm750fb`, `rtl8723bs`). Focused on board bring-up, kernel drivers, and low-level systems programming.

### Experience

- **Kernel Engineering Intern (BSP Team)** · **Harman International**, Bengaluru *(May 2026 – Present)*  
  - Working on Android (AOSP) and the QNX hypervisor for the Intelligent Cockpit Platform across kernel, HAL, and application layers.  
  - Board bring-up and testing for the QNN NPU on the BSP; using QNX PPS for shared memory with Android-side drivers.  
  - Built a pyserial MCP daemon exposing UART console tools so AI agents can execute diagnostics on live targets.  
  - Debugging display issues, bringing up new panels, and validating builds via Android VTS and overnight test scripts.

- **Software Engineering Intern** · **LunarEdge IT Solutions**, Jaipur *(Nov 2025 – May 2026)*  
  - Built backend services in Node.js, PostgreSQL, and Redis for maritime tracking (115K+ records) and e-commerce.  
  - Reduced API response times from 400ms to ~5ms using Redis caching.  
  - Developed real-time notification pipelines with Redis, Server-Sent Events (SSE), and PostGIS; containerized with Docker.
